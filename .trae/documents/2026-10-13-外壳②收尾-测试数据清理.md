## 计划

### Step 1：清理残留数据

用 backend/.venv 的 python 执行一次性脚本（在 `backend` 目录、禁用沙箱），按序删除「测试克隆行业」的 nginx_configs 与行业行，并打印清理结果确认：

```python
# 一次性清理脚本：删除冒烟残留的「测试克隆行业」
from app.database import SessionLocal
from app.models.industry import Industry
from app.models.nginx import NginxConfig
from sqlalchemy import select

with SessionLocal() as db:
    rows = db.execute(select(Industry).where(Industry.name == "测试克隆行业")).scalars().all()
    for ind in rows:
        cfgs = db.execute(select(NginxConfig).where(NginxConfig.industry_id == ind.id)).scalars().all()
        for c in cfgs:
            db.delete(c)
        db.delete(ind)
    db.commit()
    remain = db.execute(select(Industry)).scalars().all()
    print("清理完成，剩余行业:", [(i.id, i.name) for i in remain])
```

先确认 `app/database.py` 中 SessionLocal 的导出名；若为 `SessionLocal` 或 `get_db` 工厂不同名，改用对应导入。验证输出应只剩「海外货运」。
