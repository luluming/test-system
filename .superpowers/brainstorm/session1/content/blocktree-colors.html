块树配色方案（整体协调）

同一段真实配置（server / location / upstream / map）用三种配色渲染。当前问题：蓝/绿/橙黄/红 高饱和多色相混排。点击卡片选你喜欢的方案。

A · 品牌蓝单色系（推荐）

所有块徽章统一在品牌蓝家族内分级（深→浅），指令名同品牌蓝；红色只留给 if 警示。整体克制、一色到底。

server 443 ssl http2 {
listen 443 ssl http2;
server_name af-ftcloud.ifleetvision.com;
location /api/ {
proxy_pass http://api_backend;
↑ 同族色分级：server 深蓝徽章 → location 浅蓝徽章
upstream api_backend {
server 10.0.0.97:20690 weight=5 max_fails=2 fail_timeout=30s;
map $http_upgrade $connection_upgrade {
default 置底 upgrade;
'' close;

B · 中性灰阶 + 单一强调

块徽章全部灰阶（surface3 底 + 灰字），指令名灰阶；仅选中块与激活态用品牌蓝。极简、几乎无色。

server 443 ssl http2 {
listen 443 ssl http2;
server_name af-ftcloud.ifleetvision.com;
location /api/ {
proxy_pass http://api_backend;
↑ 无彩色徽章，仅边框/背景层次区分
upstream api_backend {
server 10.0.0.97:20690 weight=5 max_fails=2 fail_timeout=30s;
map $http_upgrade $connection_upgrade {
default 置底 upgrade;

C · 双色族分层

http 上下文（server/location）用品牌蓝；stream/upstream 用青绿；map 用灰蓝；if 红。按语境分层、两个色族。

server 443 ssl http2 {
listen 443 ssl http2;
server_name af-ftcloud.ifleetvision.com;
upstream db_backend_3306 {
server 10.0.0.97:3306;
map $http_upgrade $connection_upgrade {
default 置底 upgrade;

我的建议

推荐 A：信息层次靠「同色分级 + 背景层次」，全页只有一个色族 + 语义红（if），最符合整体协调；B 过于单调，C 两色族在混排时仍会显得「彩色」。最终也都会同步适配顶部标签/全局拓扑等区域。
