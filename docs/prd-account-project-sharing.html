账号管理与项目共享 PRD

版本 v1.2日期 2026-10-30状态 待评审 范围：账号体系 · 项目共享 · 行业 → 项目（Nginx / YML / 环境变量） v1.1 对象层级调整为「行业 → 项目 → 配置」；v1.2 预置行业：货运 / 国内货运 / 出租 / 公交 / 矿山

1. 背景与目标

现有配置管理平台以「行业」为顶层容器，行业内直接管理 Nginx 配置与 YML 配置，支持版本快照、差异对比、命令行推送（一次性 Token）。当前系统只有单一登录账号，没有账号体系与权限概念；行业下的配置没有更细的分组，也没有环境变量的独立管理能力。本期在行业之下引入「项目」层级：一个行业下挂多个项目，每个项目独立管理自己的 Nginx 配置、YML 配置与环境变量，项目同时是共享与权限控制的基本单位。

观察到的现状带来的问题
只有一个登录账号，所有人共用无法区分操作者，出问题无法追责；离职/换人只能改密码并通知所有人
任何登录者可见、可改全部行业配置配置无边界，跨团队误改风险高；只读协作方也拥有完整编辑权
环境变量散落在各 YML 文件里硬编码同一变量多处重复、改一处漏一处；变量值（如 IP、密钥）无法在项目维度统一查看

目标（可观察结果）

  • 系统管理员可以创建、停用、重置账号；普通用户用独立账号登录，登录行为可区分到人。
  • 项目 Owner 可以把项目共享给「所有人」或「指定人」，并分别授予「可查看 / 可编辑」权限；被共享人登录后在自己的项目列表中看到对应项目，且只能在被授权范围内操作。
  • 行业下的每个项目可以集中管理自己的 Nginx 配置、YML 配置与环境变量（键值对），并在同一项目详情页中统一查看。

2. 产品模型

2.1 角色

角色定义核心能力
系统管理员平台运维方，全系统唯一预置，不可被删除/停用管理全部账号；查看与管理全部项目（含共享设置）
普通用户由管理员创建的账号在行业下创建并管理自己的项目；共享项目给他人；在被授权范围内查看/编辑他人项目

「查看者 / 编辑者」不是独立账号角色，而是项目级共享授权：同一账号在项目 A 可以是编辑者，在项目 B 只是查看者。

2.2 对象模型

行业 Industry1 ─ n 项目 Project1 ─ n Nginx 配置 / YML 配置 / 环境变量
项目 Project1 ─ n 共享授权 ShareGrantn ─ 1 账号 User
  • 行业：现有顶层容器不变（对应现有「行业管理」），作为组织分组层，本身不承载权限。系统预置五个行业：货运、国内货运、出租、公交、矿山，后续仅系统管理员可增删。
  • 项目：行业下的配置分组，是共享与权限控制的基本单位。字段：名称、编码、负责人（Owner）、备注、创建时间；一个项目仅属于一个行业，归属创建后不可变更。
  • Nginx 配置 / YML 配置：归属于项目，每个项目维护自己的一套配置；编辑、版本快照、diff 对比、命令行推送等能力沿用现有实现。
  • 环境变量：项目级键值对（键 / 值 / 备注），不区分生产/测试环境。
  • 共享授权：记录「项目 × 对象（全员或指定账号）× 权限档位」。

3. 范围

优先级内容
P0 账号管理（管理员建号/停用/重置密码；用户改自己密码）· 项目 CRUD（行业下创建/编辑/删除）· 项目共享（全员/指定人、查看/编辑、变更与撤销）· 项目详情统一入口（Nginx / YML / 环境变量，配置能力沿用现有实现）· 环境变量 CRUD · 全量权限控制（页面可见性 + 操作拦截）
P1 共享操作记录（谁何时共享/撤销）· 环境变量批量导入导出 · 敏感变量值掩码显示
排除 环境变量按环境（生产/预发/测试）分组 · 变量在配置中的模板引用（如 {{var}}）· SSO / LDAP · 自助注册 · 审批流

P0 最小完整旅程：管理员创建账号 → 用户登录，在行业下创建项目 → 在项目内管理 nginx/yml/环境变量 → 共享给指定人（可编辑）→ 指定人登录看到项目并完成一次配置修改；恢复路径：Owner 撤销共享后，被撤销人立即失去访问。

4. 功能需求

FR-01登录与账号管理P0

目的

让每个操作者用独立账号登录，管理员集中管理账号生命周期。

登录（沿用现有行为）

  • 用户名 + 密码 + 图形验证码登录；连续 60 分钟无操作自动退出（现有空闲超时机制不变）。
  • 账号被停用后，该账号的登录态立即失效，再次请求跳回登录页并提示「账号已被停用，请联系管理员」。

账号管理（仅系统管理员可见）

入口：侧边菜单「账号管理」。页面为账号列表 + 新建按钮。

动作规则
新建账号必填：用户名（3–50 位，字母开头，仅字母/数字/下划线，全系统唯一）、邮箱（唯一）、初始密码（≥8 位，含字母与数字）。创建后默认启用。
启用 / 停用停用即时生效：该账号所有登录态失效，且无法再登录；其创建的项目与共享授权保留不删。可随时重新启用。
重置密码管理员设置新密码（同初始密码规则），重置后该账号所有旧登录态失效。
删除账号名下仍有项目的账号禁止删除，按钮置灰并提示「该账号名下有 N 个项目，请先转移或删除」；名下无项目时删除需二次确认。系统管理员自身不可被停用/删除。
修改密码（本人）任意登录用户在个人菜单修改自己的密码，需校验旧密码；成功后当前登录态保持，其他设备的登录态失效。
交互 DEMO · 账号管理列表（停用 / 删除阻止）
用户名邮箱名下项目状态操作

点击「停用/启用」切换状态；点击「删除」观察名下有项目时的阻止提示。

FR-02项目管理P0

目的

在行业之下提供配置分组容器，把一套 Nginx 配置、YML 配置与环境变量归拢到一个可共享的边界内。

入口与列表

  • 从行业进入：行业列表 → 行业详情页展示该行业下的项目列表。行业与项目名称结构对所有登录用户可见（名称本身不设权限），项目内容按授权控制。
  • 系统预置五个行业：货运、国内货运、出租、公交、矿山；行业的新建 / 编辑 / 删除仅系统管理员（见权限矩阵）。
  • 项目列表分两个页签：我的项目（我创建的）、共享给我的（全员共享 + 指定人共享，带权限标识）。系统管理员额外看到「全部项目」。
  • 列表字段：项目名称、编码、负责人、配置数量（nginx / yml / 环境变量条数）、更新时间、我的权限（负责人 / 可编辑 / 可查看）。

新建 / 编辑项目

字段规则
所属行业创建时选定，创建后不可变更（避免配置在未知范围间移动）
项目名称必填，≤50 字，同一行业内不可重名
项目编码必填，≤50 位小写字母/数字/中划线，同一行业内唯一，创建后不可修改
备注选填，≤255 字

删除项目

  • 仅项目 Owner 与系统管理员可删除，需输入项目名称二次确认。
  • 非空项目禁止删除：项目下仍有 Nginx/YML 配置或环境变量时，删除按钮置灰并提示「请先清空项目下的配置与环境变量」。避免连带删除配置造成不可逆损失。
FR-03项目共享P0

目的

让项目 Owner 控制「谁能看见、谁能改」，覆盖「给所有人看」与「给指定人看/改」两类协作场景。

触发

项目列表行操作与项目详情页均有「共享」入口。仅 Owner 与系统管理员可见该入口。

共享弹窗规则

共享方式规则
全员可见（开关） 开启后，所有启用状态的账号在项目列表「共享给我的」中可见本项目，权限固定为可查看。全员共享不开放编辑——面向未知人群的编辑权风险不可控，这是有意收窄的产品决策。
指定人（列表） 按用户名/邮箱搜索添加；每人单独设置 可查看 或 可编辑。可随时修改档位或移除，即时生效。不可添加项目 Owner 本人（重复添加同一用户时视为修改权限档位）。
  • 两种方式可叠加：同一用户同时命中多条授权时，取最高权限（如全员可查看 + 指定可编辑 → 可编辑）。
  • 共享给已停用账号：允许配置但账号停用期间不生效，账号重新启用后自动恢复。

FR-04项目详情与配置管理P0

布局

项目详情页分四个区域：项目信息（所属行业/名称/编码/负责人/备注 + 共享入口）、Nginx 配置、YML 配置、环境变量（见 FR-05）。配置编辑全部沿用现有能力：在线编辑、版本快照、diff 对比、命令行推送（一次性 Token）、回滚。

权限表现

我的权限页面表现
可查看所有内容只读；编辑/删除/推送/共享按钮隐藏或置灰；YML/Nginx 编辑器进入只读模式，版本快照可查看
可编辑可在项目内增删改 Nginx/YML 配置、生成推送 Token、管理环境变量；无共享入口、不可删除项目
负责人全部能力 + 共享管理 + 删除项目

无权限用户直接访问项目 URL 时，返回 403 提示页「你没有该项目的访问权限」。

FR-05环境变量管理P0

目的

把散落在配置中的变量集中到项目维度统一维护与查看。

字段

字段规则
变量键必填；^[A-Za-z_][A-Za-z0-9_]*$，≤128 字符；同一项目内唯一（创建/改名时校验，冲突提示「该变量已存在」）
变量值必填，≤4096 字符，支持多行文本
备注选填，≤255 字，用于说明用途

行为

  • 列表：键 / 值（过长截断，悬停显示完整值）/ 备注 / 更新时间 / 更新人；支持按键与值搜索。
  • 新增、编辑、删除：删除需二次确认（变量可能被配置引用，删除不可撤销）。
  • 权限：可查看 → 只读列表；可编辑及以上 → 可增删改。

说明：本期为纯键值对管理，不与 YML/Nginx 配置做模板变量替换（已列入排除项）。

共享授权状态

  • 权限判断一律以服务端为准，前端隐藏按钮仅为体验优化。

6. 异常与边界

场景产品行为
账号被停用时处于登录状态下一次请求即失效，跳转登录页并提示原因

环境变量键冲突 / 格式非法表单内联报错，不落库
YML 并发编辑冲突沿用现有乐观锁与版本快照机制，不在本期改动
