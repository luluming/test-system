启用 SSL 导出

        ✕
      

    

    

      
关闭「启用 SSL」后，导出将移除 ssl_protocols / ssl_certificate / ssl_ciphers 等指令，并把改写 listen X ssl http2 为 listen X http2（非 SSL 场景）。导出支持两处自动替换：server_name 域名（→ 全局新域名）与 upstream 后端整组替换（见下）。

      
域名替换（server_name → 新域名）

      
导出时，配置中所有 server_name 的值整体替换为下方填的新域名；留空则不替换域名。预览命中行标黄并标注原值。

      
      
upstream 后端整组替换（默认 + 例外覆盖）

      
只填纯 IP：导出时仅替换各组后端的 IP，端口与端口后的参数（weight 等）自动沿用该组原节点对应位置，无需手写。一个 IP = 一个后端节点。底部「默认 IP」应用到未被任何例外覆盖的全部组；下方「例外」只填需要不同的组（例：C 组 1 个 IP、其它组 3 个 IP —— 默认填 3 个，例外把 C 单独改为 1 个）。

      
默认后端 IP（应用到未被例外交代的组）

      
      
例外覆盖（仅差异化的组）

新增块

      ✕
    

    

      
在 http 顶级新增一个块，与其他 server / map / upstream 同级；`split_clients` / `geo` 与 map 同属「变量映射」块，渲染沿用 default 置底 + 正则键原样。生成的空块可直接在块管理用「+ KV」补内容。

      
块类型

      

        server
        map
        split_clients
        geo
        upstream
        stream
        events
      

      
      

        

          

          

        

      

      
      

        

          

          

        

        
生成 map $src $dst {} 空块，之后用「+ KV」填入正则匹配键与 default 行；default 会自动置底。

      

      
      

        

          

          

        

        
生成 split_clients $src $dst {}，按比例分流（A/B / 灰度）；内部行（20%… 等）在「+ KV」补。

      

      
      

        

        
生成 geo $var { default 0; 网段=值; }，default/网段行用「+ KV」补。
